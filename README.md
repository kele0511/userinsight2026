# 易小助 · 同事分享包

对话式展业工作台（客户经理端）+ 运营台（后台）+ FastAPI 控制面。

本目录是整理后的交付副本，可直接打包发给同事。不含 `node_modules`、本地数据库和 API Key。

## 建议阅读顺序

1. 先看 `01-产品PRD/` 两份冻结 PRD，了解要做什么
2. 想看界面：打开 `04-静态原型/index.html`（客户经理）和 `04-静态原型/admin/index.html`（运营台）
3. 对外讲解：用 `05-演示稿/营销AI交流PPT_V4.1.pptx`
4. 要跑工程：进入 `03-工程代码/`，按该目录 README 启动

## 目录说明

| 目录 | 内容 |
| --- | --- |
| `01-产品PRD/` | 冻结产品需求：展业助手 PRD、后端管理 PRD、设计标准、需求规格说明书 |
| `02-详细设计文档/` | 业务分析、需求拆解、架构、技术方案、交互、界面、参考资料、项目记忆 |
| `03-工程代码/` | 可运行源码：`backend` / `web-rm` / `web-admin` |
| `04-静态原型/` | 不装环境也能看的 HTML 原型 |
| `05-演示稿/` | 交流 PPT（推荐 V4.1）及逐页讲稿 |

详细设计文档的英文子目录对照见 `02-详细设计文档/文档目录.md`。
